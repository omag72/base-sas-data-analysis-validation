
# Base SAS Data Analysis & Validation Project

## Overview
This project demonstrates data cleaning, validation, and statistical analysis using Base SAS.  
It simulates a real-world analytical workflow where raw data is transformed into analysis-ready datasets, validated, and summarized for reporting purposes.

The project showcases foundational statistical programming skills relevant to clinical data environments.

---

## Objectives
- Import and structure raw datasets
- Perform data cleaning and validation
- Create derived variables
- Generate descriptive statistics and summaries
- Conduct grouped analysis using SQL procedures

---

## Tools & Technologies
- Base SAS
- PROC SQL
- PROC MEANS
- PROC FREQ
- DATA Step processing

---

## Dataset Description
The dataset contains simulated sales records including:
- Customer ID
- Name
- Age
- Region
- Sales values

It includes intentional issues such as:
- Missing values
- Duplicate records
- Inconsistent data entries

---

## Key Steps

### 1. Data Import
Raw dataset is created using a SAS DATA step.

### 2. Data Cleaning
- Removal of duplicate records  
- Handling missing values  
- Creation of derived variables (Performance category)

### 3. Statistical Analysis
- Descriptive statistics (mean, min, max)  
- Frequency distributions by region and performance  

### 4. Data Validation
- Aggregation checks using PROC SQL  
- Group-level analysis of sales performance  

---

## Example Outputs
- Summary statistics of sales and age  
- Regional performance breakdown  
- Frequency distribution of performance categories
